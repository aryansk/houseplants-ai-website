# HousePlants.ai — Website

Marketing site for the HousePlants iOS app.

Pure static HTML + Tailwind (via CDN). No build step.

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

- **Vercel** — `vercel` from this directory, or import the repo in the dashboard
- **Cloudflare Pages** — connect the repo, no build command, output directory `/`
- **Netlify** — connect the repo, no build command, publish directory `.`
